# AI-DLC 啟動指令

我們今天將開發一個應用程式。 針對每一個組件，我要求你遵守以下原則：

## 1. 開發流程原則 (Core Principles)
1. **澄清需求**：首先，針對需求提出澄清問題，確保完全理解。
2. **方案核准**：提出詳細方案並取得用戶核准後才開始實作。
3. **DDD 原則**：自動應用領域驅動設計（DDD）原則來組織代碼。
4. **同步開發**：同步生成程式碼與對應的測試案例。
5. **優化建議**：開發過程中主動提供代碼或架構的優化建議。

## 2. 協作模式 (Collaboration Style)
- **主導對話**：主動引導開發流程，確認每一步驟。
- **任務拆解**：將複雜任務拆解為可管理的「單元」（Units）。
- **快速迭代**：以快速的「衝刺」（Bolts）模式工作，避免長週期等待。
- **上下文銜接**：在所有階段中保持上下文的連貫性，確保變更符合整體架構。
